# AX Crew 0.2.6

[English](0.2.6.md) | **简体中文**

桌面端新增会话操作和变更面板。每条用户消息与模型回复都可复制；回复上的分支按钮会使用该位置之前的文本创建独立会话，继承工作目录与执行环境，不复制工具状态，也不修改原会话。轮次中修改的文件列在回复下方；点击文件或“查看变更”可打开变更面板，在保存的 diff 与当前文件内容之间切换。

已发送图片和输入框中的图片均可点击预览；历史图片从原工作目录读取。选中文本后可以添加到输入框，也可以在侧边聊天中询问相关问题。侧边聊天使用独立的只读 AX 会话，切换页签时保留其对话；后端保留对应任务与历史。
