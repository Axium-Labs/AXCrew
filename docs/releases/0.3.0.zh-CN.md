# AX Crew 0.3.0

[English](0.3.0.md) | **简体中文**

改进 AX 更新器，并加入 GitCode Release 镜像。桌面 AX 更新路径新增重试与回退处理；发布来源从官方 GitHub Release 解析和下载，失败时回退到镜像，并对照同一精确 tag 校验归档及 `SHA256SUMS`。GitCode 镜像工作流同步 GitHub Release；旧版 AX 更新器遇到网络错误时，更新器也能回退到官方安装器。

Windows 安装器先重命名现有可执行文件，再复制已验证的新文件；复制失败时恢复旧文件。仍被运行中任务占用的备份会保留，直到可以删除。

本版本还将仓库整理为 `apps/` / `crates/` 产品单仓库：控制平面位于 `crates/server/`，桌面客户端位于 `apps/desktop/`，Android 客户端位于 `apps/android/`。
