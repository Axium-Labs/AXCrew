# AX Crew 0.3.4

[English](0.3.4.md) | **简体中文**

- 继续完善可选分布式控制平面，增加主机清单与实例能力管理。
- 增加由本地 AX 执行的 SSH 主机选择和项目管理，支持多个已配置 SSH 主机，无需在远程安装 AX。
- 改进会话任务/工具展示、模型与供应商支持的推理强度控制、逐会话草稿保留、响应式布局和任务历史导航。
- 优化连接设置与项目创建流程。
- Android 版本元数据和发布产物未变更。

开发阶段验证：桌面 UI 测试、浏览器布局/交互检查、服务器与 Tauri Rust 测试，以及开发期间的生产构建均通过。本次发布未额外运行测试套件。
