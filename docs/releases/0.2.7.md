# AX Crew 0.2.7

Adaptive composers and capability imports. The session composer grows with
text and panel width and scrolls once it reaches its upper bound. The
providers list in Settings uses aligned columns that wrap on narrow windows.

The import page scans the user directory and the current project for Codex,
Cursor, Claude Code, Windsurf and shared `.agents/skills` configuration,
letting you check individual skill packages or a whole MCP configuration to
import into the current project or global AX, and also supports picking a path
manually. Scanning only reads configuration; imports report per-item results,
name conflicts are left to AX to reject, and failed items stay available for
retry.
