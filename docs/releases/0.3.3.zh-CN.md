# AX Crew 0.3.3

[English](0.3.3.md) | **简体中文**

- 新增可选的分布式控制平面，明确区分 Host、AX Instance 和 Execution 身份，允许同一主机上的多个运行时并发工作。
- 按获准的 AX 角色、Skills/MCP/Tools、模型、权限、环境标签，以及同一 Host 上各实例共享的资源预留来调度。
- 持久化 Durable Tasks、有序 Events、不可变 SHA-256 Artifacts 和带版本的 Workflow State。中央所有权、实例化标识/代次围栏隔离、幂等请求、重试/取消和检查点恢复，可应对工作进程丢失与 Crew 重启，无需始终存活的协调 Agent。
- 新增桌面 **Distributed / 分布式协作** 侧栏管理页，涵盖注册与私有工作进程配置、Host 容量/策略、任务提交/执行尝试/错误、Workflow 检查点、取消/重试、Artifact 下载与观察记录。
- 保留旧 API、单机 AX 与既有设备控制。不会复制完整 AX Session/Memory；只按逻辑项目身份共享所选结果、检查点和明确发布的 Artifact。

开发阶段验证：15 项既有服务器测试与 8 项分布式回归通过；桌面 114 项 Vitest 测试与 4 项浏览器布局/恢复检查通过，旧侧栏检查和 4 个既有进程测试套件也通过。使用 3 个真实 AX 进程、2 个逻辑 Host 的协作，验证了测试失败、分析、Patch 传递、复测、认证作用域和 Crew 重启。Android 构建、单元测试和 lint 在功能开发期间通过。生产 Windows x64 前端/网关/NSIS 构建通过；本次发布未额外运行测试。Android 版本和发布产物未变更。

限制：单个权威 Crew 进程配合 SQLite；执行尝试采用至少一次语义；资源预留不等于操作系统配额；Artifact 上限为 8 MiB；无自动 GC 或复制共识。真实物理网络/TLS/GPU 隔离未经测试；模拟模型的集成夹具明确关闭了沙箱。

要求 AX 0.3.7 工作进程。详见[分布式协作](../distributed-collaboration.zh-CN.md)。
