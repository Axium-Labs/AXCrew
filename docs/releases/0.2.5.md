# AX Crew 0.2.5

Each tool call now has one compact row that updates in place from running to success or failure. Explanations remain ordinary chat text. Expand a row to inspect the actual tool type, formatted operation, bounded output and explicit result status; raw JSON is hidden by default.

Long output scrolls inside the card, elapsed time uses minutes and hours when needed, and each turn can show its changed files with additions and deletions. Live events and local history replay preserve call IDs and failures.

Desktop, gateway and Android version metadata are synchronized to 0.2.5; Android versionCode is 7.
