# AX Crew 0.3.12

- Publishes Windows x64 NSIS, Linux x64 Debian/AppImage, Linux ARM64 Debian, and macOS Intel/Apple Silicon DMG installers from the shared desktop source.
- Collects platform installers into one release with a shared SHA256SUMS.
- Includes the current architecture and runtime-boundary documentation updates.
- Android version and binaries remain unchanged.
- macOS installers are unsigned and not notarized; platform security approval may be required.

Validation: release CI builds each native platform. Automated test suites are not run as part of this quick release; a successful build does not establish runtime acceptance on every platform.
