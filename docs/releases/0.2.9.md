# AX Crew 0.2.9

Subagent controls and installer fixes. Desktop Settings > AX gains a
**Subagents** switch that defaults off, saves through AX's
`settings --subagent` command and applies on the next agent turn; Crew shows
the persisted AX value and retains it when saving fails.

The Windows installer registers the full paths of the desktop and gateway
binaries under the install directory with the native Restart Manager API
before overwriting or uninstalling files, releasing locks and waiting for exit,
so an orphaned gateway process can no longer hold `bin/ax-crew.exe`. This does
not start PowerShell, use encoded scripts, or bypass the ExecutionPolicy.
