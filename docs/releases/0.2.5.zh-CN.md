# AX Crew 0.2.5

[English](0.2.5.md) | **简体中文**

每次工具调用现在使用一个紧凑行，在原位置从运行中更新为成功或失败。解释仍作为普通聊天文本显示。展开工具行可查看实际工具类型、格式化操作、有界输出及明确的结果状态；默认隐藏原始 JSON。

较长输出在卡片内滚动，耗时按需要显示分钟和小时；每个轮次可展示修改过的文件以及新增、删除行数。实时事件和本地历史重放保留调用 ID 与失败信息。

桌面端、网关和 Android 的版本元数据统一为 0.2.5；Android versionCode 为 7。
