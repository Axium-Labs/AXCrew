# AX Crew 0.3.0

AX updater improvements and a GitCode release mirror. The desktop AX update
path gained retry and fallback handling, and the release source now resolves
and downloads from the official GitHub Release (falling back to the mirror)
with the archive and `SHA256SUMS` verified against that exact tag. A
GitCode mirror workflow mirrors GitHub releases, and the updater can fall back
to the official installer when an older AX updater hits a network error.

The Windows installer renames an existing executable before copying the
verified replacement and restores it if copying fails; a backup still in use by
a running task is retained until it can be removed.

This release also restructured the repository into an `apps/` / `crates/`
product monorepo: the control plane lives in `crates/server/`, the desktop
client in `apps/desktop/`, and the Android client in `apps/android/`.
