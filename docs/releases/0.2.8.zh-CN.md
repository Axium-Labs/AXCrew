# AX Crew 0.2.8

[English](0.2.8.md) | **简体中文**

Agent 环境与终端 Shell 设置。桌面“设置 > AX”新增 **Agent environment**（Windows 原生 / WSL）和 **Integrated terminal shell**（PowerShell / Command Prompt / Git Bash / WSL）。这些设置与 `ax environment` 及 AX TUI 的 `/environment` 菜单共享，并应用于新 AX 进程和新终端页签。选择 WSL 前，必须在默认 WSL 发行版中的 `~/.local/bin/ax` 安装 Linux AX；Crew 会在保存前检查其可用性。桌面子进程使用 Crew 的 `AX_HOME`，默认为 `~/.ax`，以保持启动器和设置一致。
