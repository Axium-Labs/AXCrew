# AX Crew 0.2.6

Conversation actions and a changes panel landed on the desktop. Each user
message and model reply can be copied; a reply's branch button creates an
independent session from the text before that point, inheriting the working
directory and execution environment without copying tool state or altering the
original session. Files changed in a turn are listed under the reply, and
clicking a file or "view changes" opens the changes panel to toggle between the
saved diff and the current file content.

Sent images and images typed into the composer can be previewed by clicking;
historical images read from the original working directory. Selecting text can
add it to the composer or ask about it in the side chat. The side chat sends to
a separate read-only AX session and keeps its conversation when switching tabs;
the backend retains its task and history.
