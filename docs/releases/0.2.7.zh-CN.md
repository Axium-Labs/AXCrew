# AX Crew 0.2.7

[English](0.2.7.md) | **简体中文**

自适应输入框与能力导入。会话输入框随文本和面板宽度增长，达到高度上限后开始滚动。设置中的模型供应商列表使用对齐列布局，窄窗口下自动换行。

导入页扫描用户目录与当前项目中的 Codex、Cursor、Claude Code、Windsurf，以及共享的 `.agents/skills` 配置。可勾选单个技能包或整份 MCP 配置，导入到当前项目或全局 AX，也可手动选择路径。扫描仅读取配置；导入逐项报告结果，同名冲突由 AX 拒绝，失败项目保留以便重试。
