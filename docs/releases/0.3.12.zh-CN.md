# AX Crew 0.3.12

[English](0.3.12.md) | **简体中文**

- 从共享桌面源码发布 Windows x64 NSIS、Linux x64 Debian/AppImage、Linux ARM64 Debian，以及 macOS Intel/Apple Silicon DMG 安装器。
- 将各平台安装器汇总到同一个 Release，并提供统一的 SHA256SUMS。
- 包含当前的架构和运行时边界文档更新。
- Android 版本和二进制文件未变更。
- macOS 安装器未签名、未经公证，可能需要用户在系统安全设置中批准运行。

验证：发布 CI 构建各原生平台。本次快速发布没有运行自动化测试套件；构建成功不代表每个平台都已通过运行时验收。
