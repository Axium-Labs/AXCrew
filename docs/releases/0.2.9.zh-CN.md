# AX Crew 0.2.9

[English](0.2.9.md) | **简体中文**

子代理控制与安装器修复。桌面“设置 > AX”新增默认关闭的 **Subagents** 开关，通过 AX 的 `settings --subagent` 命令保存，并从下一 Agent 轮次生效。Crew 显示 AX 已持久化的值；保存失败时保留原值。

Windows 安装器在覆盖或卸载文件前，通过原生 Restart Manager API 注册安装目录下桌面程序和网关二进制文件的完整路径，释放文件锁并等待退出，避免孤立网关进程一直占用 `bin/ax-crew.exe`。此过程不会启动 PowerShell、使用编码脚本或绕过 ExecutionPolicy。
