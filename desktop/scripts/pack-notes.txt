AX Crew {{VERSION}}（Windows x64 便携版 · {{DATE}} 构建）

【怎么运行】
1. 把整个文件夹解压到任意位置（不要只拷 exe —— bin 目录必须和 exe 放在同级）
2. 双击 ax-crew-desktop.exe

【首次使用】
1. 打开「设置 → 本地 AX → AX 更新」，点「下载并安装 AX」先装好 AX 运行时
   （AX 不再随包捆绑，从这里通过 GitHub 官方安装脚本安装并写入 PATH）
2. 打开「设置 → 模型与登录」，选一个模型提供商并填入你自己的 API Key
   （不填的话代理跑不了任务；这个 key 不会随安装包一起分发，每人自己填）
   保存后界面会直接告诉你发现并缓存了多少个模型；发现失败时会给出厂商返回的原因
3. 需要时可在「设置 → 本地 AX」查看 AX 运行状态
4. 如果打开后窗口空白或报错，先装 Microsoft Edge WebView2 Runtime
   （Windows 11 一般自带，Windows 10 可能需要单独安装）

【界面语言】
标题栏左上角有一个「EN / 中」按钮，点一下即可在中英文之间切换，选择会记住。
目前英文覆盖：标题栏、左侧导航、命令面板（Ctrl+K）、终端面板、整个会话界面
（含消息区、输入框、目标循环弹窗、工作区文件面板）。其余页面暂时仍是中文。

【{{VERSION}} 改了什么】
- AX 不再随包捆绑：Crew 运行的 AX 改为「通过 GitHub 安装的那一份」
  （官方安装脚本装到 %LOCALAPPDATA%\Programs\AX\bin 并写入 PATH）。
  设置页的「AX 更新」可以检测 GitHub 上的最新版本并一键安装/更新，
  更新后 Crew 立即使用新版本 —— 不再被发行包里那份旧的 ax 顶替
- 「设置 → 本地 AX」里新增 AX 更新：点「检查更新」去 GitHub Releases 比对版本，
  本机装了 AX 就直接更新（ax --update，带 SHA256 校验），没装过则用 AX 官方
  安装脚本装上并写入 PATH；跑完把安装器/升级器说了什么原样贴出来
- 设置里新增「AX 能力」页（「本地 AX」下面）：列出 AX 现在能用的技能、
  MCP 服务器和内置工具。技能会标出「缺少工具」，MCP 服务器带启用状态和它
  声明的能力；目录按当前会话选的目录去查，没选目录时只显示全局技能与内置工具
- 会话记录重新排版：一轮里「思考 + 工具调用 + 中间说明」收进一行折叠条，
  点开才展开逐步明细；工具行不再显示 call_00_xxx 这种原始调用 ID
- 保存 API Key 后立刻做模型发现并写入 ~/.ax/models/<provider>.json；
  「刷新模型列表」现在是真的去发现，而不是只重读缓存
- 不再弹出控制台黑窗：网关与所有 ax / icacls 探测都改为无窗口启动；
  设置页与文件列表不再卡顿，耗时的探测与扫描移出界面线程并做了缓存

【说明】
- 便携版：不写注册表、不需要管理员权限，卸载直接删整个文件夹
- 数据放在 %APPDATA%\dev.axcrew.desktop（crew.sqlite3 和默认工作区都在这里；
  想彻底清空数据可把该目录一并删掉）
- 第一次双击若被 Windows SmartScreen 拦下，点「更多信息 → 仍要运行」
  （未签名程序的正常提示）
- 要求 Windows 10/11 x64
